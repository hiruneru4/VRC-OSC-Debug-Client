# VRC OSC Debug Client

VRChat の **公式 OSC** を使って、アバターの操作、パラメータの確認・変更、カメラ操作、マクロ、ログの確認をまとめて行える Windows 用のデバッグツールです。
VRChat 側の状態 (移動・マイク・ジェスチャー・身長・AFK など) もリアルタイムに表示できるので、OSC の動作確認やアバターギミックのデバッグに使えます。

- バージョン: 1.0.0.0
- C# / WinForms / .NET 8 (外部ライブラリなし。OSC の送受信も自前で実装)
- 日本語 / English 表示、ライト / ダークテーマ、高 DPI 対応

> このツールは VRChat の OSC を利用したデバッグ等のために作成されています。すべての機能は公式の OSC のみを使用しており、非公式な仕組みは利用していません。
> 使用によって発生したトラブル等について、作者は一切の責任を負いません。自己責任でご利用ください。

## ビルドと起動

```
git clone https://github.com/hiruneru4/VRC-OSC-Debug-Client.git
cd VRC-OSC-Debug-Client
dotnet build -c Release
dotnet run -c Release
```

Visual Studio 2022 で `VRC OSC Debug Client.csproj` を開いて実行することもできます。
実行ファイルを作る場合 (出力: `bin/Release/net8.0-windows/win-x64/publish/VRC OSC Debug Client.exe`):

```
dotnet publish -c Release -r win-x64 --self-contained false
```

英語表示に使う `Lang/en.txt` は実行ファイルと同じフォルダの `Lang` に自動でコピーされます。

## 使い方

1. VRChat で **アクションメニュー → Options → OSC → Enabled** を ON にします
2. ツールを起動し、確認画面で **はい** を押します (**いいえ** で終了)
3. 上部の **接続** を押します (同じ PC なら IP `127.0.0.1`、送信 `9000`、受信 `9001` のままで OK)
4. 右上に VRChat の状態が表示されれば受信できています
5. 各タブで操作します。困った時は **■ 全停止** (既定 `Ctrl+Alt+F12`) ですべて止められます

## 機能一覧

### 全体

| 機能 | 内容 |
|---|---|
| 接続 | IP・送信ポート・受信ポートを指定して接続 / 受信のみ OFF / 起動時に自動接続 |
| 全停止 | 実行中の操作・連打・コンボ・マクロ・チャット連打を止め、全ボタン・全軸を 0 に戻す (ショートカットキー対応、他アプリにキーを取られても効く監視つき) |
| 出力 ON / OFF | すべての送信を一時的に遮断 (ショートカットキー対応) |
| 現在の状態 (右上) | 移動 (向き・速さ) / 状態 (立ち・座り・空中、VR・デスクトップ) / マイク / 身長 (目の高さ) / ジェスチャー (上に右手・下に左手) / AFK を 2 行ずつ表示 |
| 動作パネル (右側) | 動作中の操作の一覧 / 操作ログ / VRC 動作履歴 (種類で絞り込み・一時停止・コピー・txt 保存) |
| タブ | 移動・視点・手・アイテム・チャット・カメラ・システム・パラメータ・マクロ・コンボ・カスタム・受信・ログ・設定 (動作中の数をバッジ表示) |

### 操作 (移動 / 視点 / 手・アイテム / システム)

| 機能 | 内容 |
|---|---|
| 入力操作 | VRChat の `/input` のボタン・軸 (前後左右・ダッシュ・ジャンプ・視点・掴む・使う・マイク・クイックメニュー・セーフモード等) |
| 実行モード | 1回 / 長押し / 連打 / 押下中。時間・回数・軸の値を操作ごとに設定 |
| 同時実行 | 複数の操作を同時に動かせる (同じ入力は全員が離すまで押されたまま) |
| カテゴリ操作 | カテゴリ停止 / 「対象」にチェックした操作をまとめて ON・OFF / ON・OFF のショートカットキー |

| アバターの大きさ | 目の高さ (m) を数値・＋−・×0.5/×2・スライダー (0.1〜100 m)・プリセットで変更 / 元に戻す / 現在値・範囲・ワールドの許可を表示 |

## 注意事項

- OSC では VRChat 内で押したキーそのものは取得できません。移動などの状態はアバターの速度などから推定しています
- AFK・ミュートなどの組み込みパラメータは読み取り専用のため、OSC からは変更できません
- 右上の「身長」は VRChat が送る目の高さ (`/avatar/eyeheight`) です
- カメラは VRChat 側で開いている時だけ操作できます。カメラドリーは VRC+ の機能です
- OSCQuery には対応していません。他の OSC ツールと同時に使う場合は受信ポートを分けてください
- 本ツールは VRChat 非公式のツールです。VRChat Inc. とは関係ありません
